# پرامپت ساخت ویدیوی معرفی مازِی (Mazey)

این سند را **کامل** به ایجنت بده. چیزی از آن کم نکن.

---

## نقش تو

تو یک کارگردان محصول + تدوین‌گر + اپراتور ویندوز هستی.
باید **مازِی را واقعاً اجرا کنی** (نه موکاپ فیک، نه اسکرین‌شات ایستا)، با موس واقعی قابلیت‌ها را نشان بدهی، و یک ویدیوی معرفی سینمایی، آرام و لوکس بسازی.

مخاطب: دانش‌آموز کنکوری گروه آموزشی ماز که لپ‌تاپ ویندوز دارد.
حس: قله، تمرکز، مسیر. نه استارتاپ شلوغ، نه گیمینگ نئون، نه تبلیغ اینستاگرامی پر از زوم.

اگر ویندوز در اختیارت نیست، اول بگو. جایگزین ضعیف (فقط `ui/index.html` در مرورگر) فقط وقتی مجاز است که اجرای واقعی غیرممکن باشد — و باید روی ویدیو بنویسی «پیش‌نمایش UI». ترجیح قطعی: نصب `Mazey-Setup.exe` روی ویندوز ۱۰/۱۱.

## مشخصات فنی خروجی

- مدت: **۴۵ تا ۷۰ ثانیه** (ترجیح ۵۵ ثانیه). نسخهٔ برش ۱۵ثانیه‌ای عمودی جداگانه اگر وقت ماند.
- نسبت: **۱۶:۹** — مستر **۱۹۲۰×۱۰۸۰** حداقل؛ اگر می‌شود **۳۸۴۰×۲۱۶۰**.
- فریم: **۶۰ fps** (اگر سیستم کشید؛ وگرنه ۳۰).
- صدا: استریو ۲۴-bit / ۴۸ kHz. VO فارسی واضح، نزدیک، آرام.
- زیرنویس فارسی درشت، پایین‌قاب، بدون اموجی.
- فرمت: `Mazey-Intro-1.0.3.mp4` (H.264 + AAC) و در صورت امکان ProRes/DNx برای آرشیو.
- نمایشگر: لپ‌تاپ، scaling ۱۰۰٪ یا ۱۲۵٪، نوار تسک پنهان یا پایین خیلی خلوت.
- جزیره باید **بالای وسط صفحه** دیده شود؛ والپیپر تیره/کوه/آبی آرام تا قرص سیاه بخواند.
- تم داخل برنامه: **Everest**. چهرهٔ استراحت: **Eyes**. تقویم: **شمسی**.

## آماده‌سازی محیط (قبل از رکورد)

1. ویندوز ۱۰/۱۱ تمیز. SmartScreen اگر آمد: More info → Run anyway.
2. نصب از Setup (بدون Admin). برنامه باید با ویندوز بالا بیاید؛ برای دمو همان جلسه کافی است باز باشد.
3. والپیپر: کوه/اورست/آبی تیره. آیکون دسکتاپ را خلوت کن (حداکثر ۴ آیکون).
4. Spotify یا Media Session: یک قطعهٔ بی‌کلام آرام پخش شود تا کاور و کنترل روی جزیره بیاید. فیلم/تمام‌صفحه پخش نکن (جزیره Hide می‌شود).
5. در تنظیمات مازِی: Theme = everest ، Resting = Eyes ، Hide روی فیلم = روشن، File shelf = روشن.
6. چند فایل آماده روی دسکتاپ: `زیست-فصل۳.pdf` ، `آزمون.pdf` (خالی هم باشد). یک لینک در کلیپ‌بورد نگذار تا شات کپی تمیز بماند.
7. کرسر: حرکت ease، نه تیک‌تیک. مکث ۰.۴–۰.۸ ثانیه روی هدف قبل از کلیک. کلیک واحد؛ دابل‌کلیک الکی نه.
8. صدا: کلیک ویندوز را کم یا خاموش؛ VO و موسیقی بستر جدا.

اگر از سورس بسازی نه از Setup:
```
cd src-tauri
cargo build --release
```
خروجی `mazey.exe`. برای دموی عمومی همان Setup ریلیز را ترجیح بده.

## ساختار زمانی (۵۵ ثانیه)

همهٔ زمان‌ها تقریبی‌اند. برش روی حرکت تمام‌شده، نه وسط انیمیشن.

### 0:00–0:06 — ورود
صفحهٔ خالی لپ‌تاپ. والپیپر کوه. جزیرهٔ باریک بالای صفحه، دو چشم زنده، یک پلک.
**بدون لوگو فوری.** دوربین خیلی آرام به بالای صفحه نزدیک می‌شود (digital push-in حداکثر ۱۱۰٪).
VO: «بالای لپ‌تاپت، یک جزیره است.»

### 0:06–0:12 — هویت
موس آرام می‌رود روی جزیره. قرص باز می‌شود: ساعت + تاریخ شمسی + دکمه‌ها. تم اورست مشخص باشد.
عنوان روی تصویر (کلمهٔ فارسی درشت، لاتین کوچک زیرش): **مازِی** / Mazey
VO: «مازِی. برای بچه‌های ماز.»

### 0:12–0:20 — ماز
موس روی دکمهٔ آبی ماز (لوگوی سر). یک کلیک.
جملهٔ انگیزشی می‌آید و حدود ۱۰ ثانیه می‌ماند. **سایت biomaze باز نشود.**
یکی از این جمله‌ها باید روی تصویر خوانا باشد:
- قله همین‌جاست. یک قدم دیگر.
- خسته شدی یعنی داری بالا می‌روی.
- یک تست دیگر. یک مبحث دیگر. اورست نزدیک است.
VO: «یک زدن؛ یک جمله. بعد برمی‌گردی سر مسیر.»
کات قبل از ناپدید شدن کامل جمله (حدود ثانیهٔ ۸ نمایش کافی است).

### 0:20–0:28 — موزیک
جزیره حالت پخش: کاور، اسم آهنگ، قبلی/بعدی. موس روی pause سپس play. اسکربر اگر هست یک کشیدن کوتاه.
VO: «آهنگ همین‌جاست. فیلم و بازی را ول می‌کند.»

### 0:28–0:36 — درس
شات A (۴ث): `Ctrl+Alt+N` — تایپ کن: `۱۰ دقیقه دیگه زیست` — Enter. یادداشت/یادآور دیده شود.
شات B (۴ث): تایمر درس را از منو باز کن، استارت. اعداد کهربا روی جزیره بماند.
VO: «یادداشت یک خط. تایمر تا آخر روی صفحه می‌ماند.»

### 0:36–0:44 — دست‌ها
فایل `زیست-فصل۳.pdf` را بکش روی جزیره؛ روی قفسه بنشیند.
سپس در مرورگر یا نوت‌پد یک لینک کپی کن؛ پیش‌نمایش کپی روی جزیره.
VO: «فایل را رها کن. لینک را کپی کن. جزیره یادش می‌ماند.»

### 0:44–0:50 — تنظیمات / تم
چرخ‌دنده، یک کلیک (نه چندبار). اسکرول تا Theme. از everest به ariamir برو **یک لحظه** (سبز برند)، بعد برگرد everest.
نشان بده چشم‌ها / ساعت / علامت ماز قابل تعویض‌اند؛ روی Eyes برگرد.
VO: «تم اورست. اگر خواستی، دنیای خودت.»

### 0:50–0:55 — خروج
جزیره به حالت چشم برمی‌گردد. کارت پایان:
- لوگوی مازِی (سر ماز) بزرگ
- Mazey 1.0.3
- github.com/irariamir/Mazey
- خط کوچک: ساختهٔ ARIAMIR — دانش‌آموز دوازدهم ریاضی
- سبز `#3ECF8E` فقط روی نام ARIAMIR
VO: «دانلود آزاد. برای ویندوز.»
پایان روی URL ریلیز، ۲ ثانیه سکوت تصویری.


## کارگردانی موس (اجباری)

- حرکت Bezier؛ شتاب نرم. هیچ teleport.
- هدف را از دست نده؛ اگر لرزید، همان شات را تکرار کن.
- Hover روی جزیره ۰.۵ ثانیه نگه دار تا انیمیشن عرض تمام شود، بعد کلیک.
- تنظیمات باید **با یک کلیک** باز شود. اگر باز نشد، شات را دور بریز و تکرار کن.
- دکمهٔ ماز را دو بار نزن.
- اسکرول تنظیمات آرام، نه فلیک.
- موقع درگ فایل: فایل را بلند کن، ۰.۳ ثانیه مکث، روی جزیره رها کن؛ انیمیشن drop دیده شود.

## موسیقی بستر

بی‌کلام، مینیمال، پد آهسته + یک پیانو یا سینث نرم. ۶۰–۹۰ BPM.
نه بیت اینستا، نه تریلر هالیوود.
ولوم بستر زیر VO؛ در شات ماز (جملهٔ قله) ۲ dB بالا، در outro دوباره پایین.
لایسنس آزاد (Epidemic/Artlist/YouTube Audio Library). نام قطعه را در کپشن یوتیوب بنویس.
