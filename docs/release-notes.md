نسخهٔ **۱.۰.۲** مازِی — ۱۷ نوامبر ۲۰۲۶

اگر **۱.۰.۰** یا **۱.۰.۱** داری، از منوی مازِی **بررسی آپدیت** را بزن. یا از پایین صفحه Setup را بردار.

## این نسخه چه چیزی را درست کرد

- لینک «چه خبر» بعد از آپدیت به همین ریپو می‌رود (قبلاً آدرس اشتباه بود).
- تنظیمات و رمزها فقط مال مازِی می‌مانند؛ پوشهٔ برنامهٔ دیگر را جابه‌جا نمی‌کند.
- متن راهنمای دکمهٔ ماز با رفتار واقعی یکی است: جمله، نه سایت.
- فایل‌های پیش‌نمایش اضافه از ریپو برداشته شد.

## فایل‌ها — کدام را بردارم

- **Mazey-Setup.exe** — نصب معمولی. برای بیشتر افراد همین کافی است. Admin نمی‌خواهد.
- **Mazey-Portable.exe** — بدون نصب؛ مستقیم اجرا می‌شود.
- **Mazey-Windows.zip** — همان برنامه داخل زیپ، با مجوز.
- **latest.json** — برای خود برنامه است. لازم نیست دانلودش کنی.

ویندوز ۱۰ یا ۱۱، با WebView2 (روی ویندوز ۱۱ هست). اگر SmartScreen آمد: More info → Run anyway.
