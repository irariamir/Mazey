اگر ۱.۰.۰ تا ۱.۰.۲ داری، از منوی مازِی **بررسی آپدیت** را بزن. یا از پایین صفحه Setup را بردار.

## این نسخه چه چیزی اضافه کرد

- حرکت جزیره، منو و چشم‌ها نرم‌تر و بدون پرش تند.
- تم‌های مایع آرام‌تر حرکت می‌کنند.
- نصب‌کننده با کلید خود مازِی امضا می‌شود؛ آپدیت داخل برنامه فایل عوض‌شده را نصب نمی‌کند.

## فایل‌ها — کدام را بردارم

- **Mazey-Setup.exe** — نصب معمولی. برای بیشتر افراد همین کافی است.
- **Mazey-Portable.exe** — بدون نصب.
- **Mazey-Windows.zip** — برنامه داخل زیپ.
- **latest.json** / **Mazey-Setup.exe.sig** — مال خود برنامه؛ لازم نیست دستی برداری.
