نسخهٔ **۱.۰.۱** مازِی — ۱۷ نوامبر ۲۰۲۶

اگر **۱.۰.۰** روی سیستم است، از منوی مازِی **بررسی آپدیت** را بزن؛ همین فایل نصب را می‌گیرد. یا از پایین صفحه، Setup را دستی دانلود کن.

## این نسخه چه چیزی اضافه کرد

- **ساعت:** کلیک روی ساعت یا تاریخ، جزیره را حدود ۱۰ ثانیه باز نگه می‌دارد تا تاریخ را بخوانی.
- **نصب‌کننده:** صفحه‌های Welcome و Finish انگلیسی‌اند تا زیر ویندوز انگلیسی به‌هم‌ریخته دیده نشوند.
- **آپدیت داخل برنامه:** «بررسی آپدیت» به همین صفحهٔ Releases وصل است.

## فایل‌ها — کدام را بردارم

- **Mazey-Setup.exe** — نصب معمولی. برای بیشتر افراد همین کافی است. Admin نمی‌خواهد. بعد از نصب، مازِی باز می‌شود.
- **Mazey-Portable.exe** — بدون نصب؛ یک‌بار اجرا می‌شود و چیزی در Programs نمی‌گذارد.
- **Mazey-Windows.zip** — همان برنامه داخل زیپ، با مجوز.
- **latest.json** — برای خود برنامه است. لازم نیست دانلودش کنی.
